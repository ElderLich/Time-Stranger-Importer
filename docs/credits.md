# Credits

## This repository

**Senator John (ElderLich)** created and maintains this version of Time Stranger Importer. His work here starts with the first commit and includes the Blender workflow tools, New Century model and skill conversion, and native export improvements. [First commit](https://github.com/ElderLich/Time-Stranger-Importer/commit/b04cdfb7467da19e616a2a4b33dc7dcc0d3a9da6)

## Earlier tools and contributors

- **Zeak** contributed to the earlier unified importer and the DSTS workflows this project builds on.
- **Nymic_Razor (Named-Blade)** contributed earlier DSTS importer tools and created the original geometry parser used by the maintained backend. [DSTS Formats Parser](https://github.com/Named-Blade/dsts-formats/tree/parser)
- **Pherakki** developed the animation serializers, DSCS Blender tools and bundled `blunger` and `exbip` foundations. [Blender Tools for DSCS](https://github.com/Pherakki/Blender-Tools-for-DSCS)
- **Romsstar** maintained earlier DSCS Blender tools. The Digimon modding community contributed practical model and animation workflows. [Romsstar’s Blender tools](https://github.com/Romsstar/Blender-Tools-for-DSCS)
- **SydMontague** developed tools for extracting and working with game assets. [DSCSTools](https://github.com/SydMontague/DSCSTools)
- **Hyotan’s workshop** documented Time Stranger modding techniques. [Time Stranger guides](https://hyotan-dev.github.io/dstsworkshop/)

Game assets are not included. Upstream components retain their original terms.
